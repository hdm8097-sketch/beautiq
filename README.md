# 💎 BeautiQ — برنامج إدارة العيادات ومراكز التجميل

نظام متكامل لإدارة العيادات ومراكز التجميل **BeautiQ**، يعمل **بالكامل داخل المتصفح**
بدون خادم وبدون إنترنت — بواجهة **عربية RTL** كاملة.

---

## 🚀 التشغيل

1. افتح مجلد `aureva`.
2. انقر مرتين على `index.html` ليُفتح في متصفحك (Chrome / Edge مُفضّل).
3. جاهز — تُزرع بيانات تجريبية أول مرة (عملاء، مواعيد، فواتير، مخزون) وتُحفظ تلقائياً في المتصفح.

---

## ✨ الوحدات

### 1) 📊 لوحة التحكم
- بطاقات مؤشرات ملوّنة (العملاء / مواعيد اليوم / إيراد الشهر / إيراد اليوم) بأيقونات.
- **جدول اليوم حسب الموظف**: كل عمود موظف ولونه — اضغط أي خانة فارغة للحجز فيها.
- رسم **الإحصائيات** (مواعيد / إيراد / عملاء) ورسم **توليد الإيرادات** مقابل المصروفات لآخر 6 أشهر.
- آخر النشاطات، تنبيهات المخزون الناقص، و6 إجراءات سريعة.

### 2) 📅 المواعيد والحجوزات
- **عرض يومي** بخط زمني (9ص–9م): اضغط أي فراغ لإضافة حجز في تلك الساعة.
- **تقويم شهري**: معاينة الحجوزات على كل يوم (مؤكد/بانتظار/منجز/ملغي) مع أزرار تنقّل.
- حجز بعدة خدمات، اختيار الموظف المسؤول، المدة والسعر يُحسبان تلقائياً.
- تذكيرات تلقائية عند فتح النظام (مواعيد الساعة القادمة / مواعيد اليوم).
- إنهاء الحجز **ينشئ فاتورة جاهزة** بالبنود تلقائياً، وطباعة جدول اليوم.

### 3) 👥 العملاء (CRM + الولاء)
- ملف كامل لكل عميل: بيانات، مصدر الوصول، ملاحظات طبية.
- سجل المواعيد والفواتير، الزيارات، الإجمالي المدفوع، الموعد القادم.
- **نقاط ولاء**: تُمنح تلقائياً مع كل فاتورة (قابلة للضبط) مع شاشة استبدال النقاط.
- طباعة ملف العميل، بحث وفلترة بالمصدر، حذف مع السجلات.

### 4) 💆 الخدمات
- كتالوج بـ 9 تخصصات (وجه، ليزر، حقن، شعر، جسم، أظافر، أسنان…) و18 خدمة جاهزة.
- سعر ومدة لكل خدمة، تفعيل/إيقاف، إحصاء مرات الحجز والإيراد منها، طباعة قائمة الأسعار.

### 5) 📦 المخزون
- منتجات ومواد بحدّ تنبيه، سعر شراء/بيع، وحدة قياس.
- حركات إدخال/استهلاك مع سجل زمني، **خصم تلقائي من المخزون عند بيع** في الفاتورة.
- تقرير النواقص المطبوع مع كمية الطلب المقترحة وتكلفتها.

### 6) 💰 المالية والفواتير
- **نقطة بيع (POS)**: بنود خدمات/منتجات، خصم، ضريبة، طرق دفع (نقدي/شبكة/تحويل/آجل).
- ملخص فوري (فرعي، خصم، ضريبة، إجمالي، نقاط مكتسبة) وإصدار وطباعة الفاتورة.
- تسجيل المصروفات بتصنيفات، وملخص مالي: منحنى إيراد 6 أشهر، أفضل الخدمات، توزيع طرق الدفع.

### 7) 👨‍⚕️ الموظفون
- ملف لكل موظف (مسمى، راتب، حالة)، **حضور/انصراف** يومي بضغطة.
- **صلاحيات مخصصة** لكل موظف (8 صلاحيات).
- إنتاجية: المواعيد المنجزة، الإيراد المُنجز، متوسط الجلسة، أيام وساعات الحضور، طباعة القائمة.

### 8) 📈 التقارير
- فلاتر فترة (يوم / 7 / 30 / الشهر / الكل): إيرادات، مصروفات، صافي، هامش، نسبة إنجاز المواعيد.
- منحنى الإيراد اليومي، أداء الخدمات، إنتاجية الموظفين، أفضل العملاء، المصروفات حسب التصنيف،
  وجدول فواتير الفترة — مع **طباعة تقرير شامل**.

### 9) ⚙️ عام
- بيانات المركز، **عملتان** (د.ع / دولار) مع سعر صرب، ضريبة وإعدادات الولاء.
- **8 ثيمات** (برتقالي / داكن / فاتح / محيطي / بنفسجي / روز / زمردي / ذهبي) تُحفظ تلقائياً.
- بحث سريع عالمي (`Ctrl + K`) لعملاء ومواعيد وفواتير وخدمات.
- **نسخ احتياطي** تصدير/استيراد JSON + تصفير البيانات.

### 10) 🔐 أمان وإدارة (قفل المدير)
- **قفل برمز PIN (4–8 أرقام)**: التعديلات والحذف وتغيير الإعدادات لا تتم إلا برمز المسؤول —
  وبدون الرمز تُعرض البيانات للمشاهدة فقط.
- يُطلب **إنشاء الرمز** عند أول محاولة تعديل، مع عرض **رمز استرداد** (طوارئ) مرة واحدة يُحفظ في مكان آمن.
- شارة حالة في الشريط العلوي: 🔒 مقفل / 🔓 الإدارة مفتوحة (تُغلق تلقائياً عند إعادة التحميل).
- تغيير الرمز أو تعطيله من الإعدادات ← «أمان وإدارة» (يتطلب الرمز أولاً).
- حماية طبقية: اعتراض أزرار التعديل + تغليف دوال الحظوظ + تجاهل أي حفظ أثناء القفل.

## 🗂️ بنية المشروع

```
aureva/
  index.html                 الصفحة الرئيسية (كل الشاشات)
  README.md                  هذا الملف
  assets/css/styles.css      التنسيقات (4 ثيمات + RTL + طباعة + تقويم/POS)
  assets/js/data.js          بيانات مرجعية (خدمات/منتجات/تصنيفات/صلاحيات)
  assets/js/store.js         التخزين المحلي + البذرة التجريبية + حسابات المال
  assets/js/ui.js            أدوات الواجهة (مودال، تنبيهات، رسوم SVG، طباعة)
  assets/js/views-appointments.js   المواعيد (يوم/شهر/تذكيرات)
  assets/js/views-clients.js        العملاء + الولاء
  assets/js/views-services.js       كتالوج الخدمات
  assets/js/views-inventory.js      المخزون والحركات
  assets/js/views-finance.js        الفواتير POS + المصروفات + الملخص
  assets/js/views-employees.js      الموظفون + الحضور + الصلاحيات
  assets/js/views-reports.js        التقارير الشاملة
  assets/js/guard.js          قفل الإدارة (رمز PIN للمدير فقط)
  assets/js/app.js           التوجيه + لوحة التحكم + الإعدادات + البحث
```

## 🔒 الخصوصية

كل البيانات محفوظة في **متصفحك فقط** (Local Storage) — لا يوجد خادم ولا رفع للبيانات.
صدّر نسخة احتياطية دورياً من زر «تصدير» بالأعلى أو من الإعدادات.

> 💡 لتفريغ البيانات التجريبية: الإعدادات ← «تصفير كل البيانات».
